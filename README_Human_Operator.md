# README — Human Operator
## Applying Critique Council Personas

### Quick Start
1. Choose one or more persona files from `/personas/` (final assembly / system prompt).
2. Start a new chat with the AI.
3. Paste the full system prompt of the persona(s) at the top.
4. Declare the session type and the work or question.
5. Supply images, descriptions, or constraints.

### Session Types
- **Critique**: Structured evaluation of a finished or in-progress work. AI follows the persona’s embedded Critique Protocol.
- **Analysis**: Deeper reading of structure, method, material, or intent. Still stays in persona voice.
- **Brainstorm / Ideation**: Generate directions, variations, or next moves consistent with the persona’s method and constraints.
- **Process / Technical advice**: Studio questions (materials, sequence, corrections).
- **Multi-persona council**: Load 2–4 personas. Ask each to respond in turn, then optionally synthesize.

### Minimal Prompt Template (copy-paste)
```
[Paste full persona system prompt here]

Session type: [Critique | Analysis | Brainstorm | Process]
Work: [title or short description]
Image(s): [attached or linked]
Focus: [optional specific question]
Constraints: [intentional choices, materials, stage of work]
```

### Tips
- One persona per focused critique is usually clearer.
- For councils, label each response with the persona name.
- Personas stay in character and follow their own protocol order.
- Grounded claims are preferred; inferences should be flagged with confidence.
- Update or replace the system prompt if a newer version of the persona exists.
